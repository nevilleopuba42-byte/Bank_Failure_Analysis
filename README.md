# Bank_Failure_Analysis
Bank failure analysis dashboard built using powerBi

This project analyzes bank failure data using power bi. it presents bank failure by state,month,city and year to help identify patterns and trends.

##TOOLS USED
powerbi
data visualization
data analysis

##Dashboard features
Bank failure counts by state
monthly distribution of bank failures
city-level bank failure table
year-based analysis using a play axis visual

##Key skills demonstrated
Building interactive dashboards
creating charts and tables
analyzing trends over time
presenting data visualy
